# data/

Здесь лежат синтетические датасеты экспериментов. В git они не хранятся, а
воспроизводятся детерминированно: один и тот же seed даёт одни и те же данные.

```bash
make data          # или: python -m abtest.datagen --outdir data
```

Дашборд генерирует их сам при первом обращении. Состав:

| Файл | Что демонстрирует |
|---|---|
| `experiment_conversion.csv` | Конверсия с реальным эффектом (+8% относит.) |
| `experiment_continuous.csv` | Непрерывная метрика (выручка) и сильный пред-период для CUPED |
| `experiment_srm_broken.csv` | Поломанный сплит (SRM) и дисбаланс ковариат, без истинного эффекта |

Спецификации датасетов заданы в `abtest.datagen.SAMPLE_SPECS`.
